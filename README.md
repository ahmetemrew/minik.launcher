# Minik Launcher 🚀

The world's lightest and fastest Android launcher. Designed for simplicity, speed, and efficiency.

## Features
- 📦 **Ultra Small:** Only **22KB** in size (listed on Play Store).
- ⚡ **Super Fast:** Zero lag, even on older devices.
- 🔋 **Battery Friendly:** Minimal background activity.
- 🎨 **Minimalist Design:** Clean app list that respects your wallpaper.
- 🚫 **No Ads / No Tracking:** Purely functional and private.

## Technical Details
- Built with pure Java and Android APIs.
- Zero external dependencies.
- ProGuard optimized for maximum shrinkage.
- Uses `QUERY_ALL_PACKAGES` to list installed apps.
